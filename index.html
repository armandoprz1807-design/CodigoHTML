🖥️ Frontend: Estructura y Estilos

El desarrollo del lado del cliente se basa en tener un código HTML limpio y semántico. Para agilizar el diseño, en lugar de escribir CSS puro todo el tiempo, se integran frameworks como Tailwind CSS y Bootstrap.

JavaScript se utiliza para manipular el DOM, creando componentes interactivos como las pestañas de navegación de este mismo archivo.

⚙️ Backend: PHP y Modelo-Vista-Controlador

El uso de PHP se organiza bajo el patrón MVC, dividiendo el proyecto de forma lógica:

  • Modelo: Archivos que se conectan a MySQL y hacen las consultas (Select, Insert).
  • Vista: El HTML que ve el usuario final.
  • Controlador: El intermediario que recibe los datos, llama al modelo y envía la respuesta a la vista.

🗄️ Diseño de Bases de Datos y Normalización

Las bases de datos se diseñan usando diagramas Entidad-Relación (ER) en MySQL Workbench y se administran en phpMyAdmin vía XAMPP.

Un punto crítico es la Normalización para mantener la integridad de los datos, por ejemplo en un sistema de Turismo Edomex:

Fase Regla Principal Aplicación Práctica
1FN Datos atómicos No tener múltiples municipios en una sola celda.
2FN Dependencia funcional completa Separar datos del municipio de los datos del estado.
3FN Sin dependencias transitivas Las tablas se relacionan estrictamente por Claves Foráneas (Foreign Keys).

☁️ Despliegue en Servidor

Una vez que el proyecto funciona en `localhost` usando XAMPP, el código se migra a un entorno de producción. Plataformas como InfinityFree permiten alojar los archivos PHP y exportar/importar la base de datos `.sql` para que el proyecto sea accesible desde cualquier dispositivo.
